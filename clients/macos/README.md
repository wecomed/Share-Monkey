# Share Monkey · Mac

当前 Mac / Windows 版本均为 **0.5.8**，使用 4 位密码与自动重连时请同时更新两端。输入协议 3、蓝牙传输协议 3。保留原生事件引用泄漏、系统按键崩溃、窗口常驻和跨屏捕获修复；本次增加断线自动恢复。

已打包的 `Share Monkey.app` 可直接运行，无需安装 Python。升级时先退出旧版，再打开新版。当前发行构建为 Apple Silicon，临时签名且未公证。

- 红色关闭按钮 / Command-W：隐藏窗口，保留共享连接、菜单栏与 Dock 图标。
- 菜单栏指针图标：打开主窗口、查看连接状态、断开或退出。
- 远控期间打开主窗口：先安全返回本机，再显示窗口，连接继续保持。
- 其他应用或系统切走捕获焦点：安全返回本机，保留连接，可以再次跨屏。
- “退出 Share Monkey” / Command-Q：真正退出并断开连接。
- 再次打开应用：唤回现有窗口，不重复启动。
- 界面跟随系统深浅色，使用系统字体、中文回退和 macOS 27 原生玻璃导航；不覆盖用户的辅助显示设置。
- 连接与等待期间避免 App Nap，允许系统正常睡眠；强制结束和休眠不在常驻图标的保护范围内。

默认控制端：另一台电脑选择接收端并开始等待；Mac 自动发现后输入相同的配对密码，4 位数字即可，在“键鼠与屏幕”调整左右位置后连接。无需填写 IP。控制端速度 25%–400% 可实时调整，Mac 默认 150%。F12 返回本机。

在“系统设置 → 隐私与安全性”允许“辅助功能”“输入监控”和询问时的本地网络访问，授权后退出重开。保留旧 bundle ID 以便权限迁移；若更新后权限失效，请重新添加新版应用。自动发现端口 UDP 24810，连接端口 TCP 24809。

使用蓝牙：两端开启系统蓝牙，在客户端选择“蓝牙直连”，键鼠所在端选“使用本机键鼠”，另一端选“接受另一台电脑控制”，填写相同的密码，4 位数字即可。连接前，在键鼠端的“键鼠与屏幕”设好左右位置。无论控制方向，**Mac 都先点击“开启蓝牙等待”**，允许系统的蓝牙访问；然后 Windows 选择发现的 SM Monkey 并点击“连接 Mac”。不需要填写 IP、COM 端口，也不需要去系统配对成键鼠。权限被拒绝时到“隐私与安全性 → 蓝牙”允许 Share Monkey，然后重开。

蓝牙支持键鼠与最多8192个 UTF-8 字节的纯文本剪贴板，不传文件；大段文本或文件请切回局域网。默认开启断线自动恢复：Mac 重新等待，Windows 自动连接。手动“断开”或退出会停止恢复，重启应用后需再输入密码。完整步骤在客户端“蓝牙配置”。请使用带蓝牙用途声明的新版 `.app`；普通终端直接运行 Python 未带声明时会拒绝启用蓝牙。

偏好保存在 `~/Library/Application Support/Share Monkey/settings.json`，不会保存配对密码。接收文件保存在 `~/Downloads/Share Monkey`。尚不支持多显示器或桌面文件拖拽。

源码 ZIP 可通过 `install.command` 安装依赖，再运行 `run-macos.command`，需要 Python 3.11+。构建命令：

```sh
.venv/bin/python -m pip install -r requirements-build.txt
.venv/bin/python tools/build_client.py macos --output-dir dist/v0.5.8
```

自动检查包含模拟加密传输、双向角色、连续跨屏和原生监听恢复。当前构建的真实 Windows 关屏/唤醒与双机耐久尚未验收，详见 [验证说明](../../docs/VALIDATION.md)。
